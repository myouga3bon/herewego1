A　説明の（　）をうめよう語群から選びます

  1. 「～は いくらですか」は How（much）is ～? と言う。
  2. 「何時に 始まりますか」は What time does ～（start）? と言う。
  3. 案内の料金は（Price）の らんを 見る。
  4. 「～を 楽しみました」は I（enjoyed）～. と言う。
  5. 「～について 多くを 学びました」は I learned a（lot）about ～. と言う。
語群：much ／ start ／ Price ／ enjoyed ／ lot
おぼえ方　How much は「いくら」。How long（どのくらい長く）と まちがえないように。
does の うしろは 原形 の start です。

B　（　）に1語ずつ書こう本文の案内です

ここがかなり大事。本文は そのまま テストに出ます。
How（much）is the 90-minute tour?（90分のツアーはいくらですか）
What time（does）the 15-euro tour start?（何時に始まりますか）
Tour A is 15（euros）.（Aツアーは15ユーロです）
I want to（see）The Mona Lisa.（モナ・リザが見たいです）
I can't（join）a daytime tour.（日中のツアーには参加できません）
I'm（free）on Wednesday and Saturday.（水曜と土曜がひまです）
I want to（learn）art history.（美術史を学びたいです）
It was really（fantastic）!（とてもすばらしかったです）
I was very（happy）to see it up close.（近くで見られてうれしかったです）
I learned a lot（about）art history.（美術史について多くを学びました）
かくにん　2 は does があるので うしろの start に s は つきません。
3 の 15 euros は 2つ以上なので s がつきます。

6 → fantastic　8 → a lot about
