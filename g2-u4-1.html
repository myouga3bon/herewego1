教科書 p.50〜51
主役
今回の文法テーマ！
There is a book on the desk.
机の上に 本が あります

1きほんの文

「机の上に 本が あります」のように、はじめて話に出すものが「ある・いる」と言うときの形です。

There は「そこに」とは訳しません。
　数によって is と are を使い分けます。

❶ものが1つのときThere is
本が 1さつ あります→There is a book
There is a book on the desk.机の上に 本が あります。
Is there a book on the desk?机の上に 本が ありますか。
うしろが a book（1つ）なら is。たずねるときは Is there ～?。
❷ものが2つ以上のときThere are
本が 2さつ あります→There are two books
There are two books on the desk.机の上に 本が 2さつ あります。
Are there two books on the desk?机の上に 本が 2さつ ありますか。
うしろが two books（2つ以上）なら are。うしろを見てから決めます。

ポイントは、主語はうしろのものだということ。
　There ではありません。

きほんの文を3回音読して、さらに3回ずつ書き写そう

2かなり大事｜be動詞はうしろの数で決まる

ここが今回のヤマです。
　ふつうの文は前の主語で be動詞が決まりますが、この文だけはうしろの名前で決まります。

There is a big garden.（1つ → is）
There are three books.（2つ以上 → are）
◯ うしろを見るa garden / three books
There is a garden.
There are two cats.
✕ There を主語あつかいいつも is にしてしまう
There is two cats.
There are a garden.

There は場所ではなく、合図のことばです。
　だから数の判断には使いません。

3テストによく出ることば

4つの形をセットでおぼえましょう。
　たずねる文は Is を前に出すだけです。

ことば使うときれい
There is1つあるときThere is a garden.
There are2つ以上あるときThere are two cats.
Is thereたずねる文Is there a garden?
There isn't否定文There isn't a garden.
There is ・ There are ・ Is there ・ There isn't を3回ずつ書き写そう！

4たずねる文・否定文・答え方

be動詞の文なので、1年生のルールがそのまま使えます。
　答えにも there を入れるのがポイントです。

作る文やり方れい文
たずねる文be動詞を前に出すIs there a garden?
否定文be動詞のうしろに notThere isn't a garden.
答え方there を入れて返す— Yes, there is. ／ No, there isn't.

Yes, it is. とは答えません。
　Yes, there is. です。

5過去のことを言うとき

過去にするときは、be動詞を was・were に変えるだけです。

There was a garden.（庭が ありました）
There were two cats.（ねこが 2ひき いました）

数の決め方は同じです。
　1つなら was、2つ以上なら were。

A　説明の（　）をうめよう語群から選びます（同じ語を2回使ってもよい）

  1. 「～がある・いる」は There（is / are）～. の形で表す。
  2. be動詞は、There ではなく（うしろ）の名前の数で決める。
  3. 2つ以上あるときは（are）を使う。
  4. たずねる文は、be動詞を（前）に出す。
  5. 答えるときも、Yes,（there）is. のように入れる。
語群：is / are ／ うしろ ／ are ／ 前 ／ there
この There は「ほら、あるよ」と合図を送るだけのことばです。中身がありません。
だから文のほんとうの主役はうしろの名前。be動詞はその数に合わせるのです。

B　is？ それとも are？（　）に入るものを書こう

ここがかなり大事。うしろの名前の数だけを見ましょう。
There（is）a big garden.
There（are）three books.
There（are）two cats.
There（is）a book on the desk.
There（are）many people.
There（is）a park near here.
There（are）three books.
There（is）a cat in the room.
（Is）there a garden?
（Are）there any books?
見分け方　a ～（1つ）→ is（1・4・6・8・9）
two・three・several・many や s のついた名前（2つ以上）→ are（2・3・5・7・10）
a が見えたら is、と覚えると速いです。

C　正しい文には ○、まちがっている文には ✕ を書こう

There is a big garden.○
There are a big garden.✕
There are two cats.○
There is two cats.✕
Is there a garden?○
Do there a garden?✕
Yes, there is.○
Yes, it is.✕
直し方　2 → There is a big garden.　4 → There are two cats.
6 → Is there a garden?（be動詞の文）　8 → Yes, there is.（there を入れる）

D　正しいほうを選ぼう

うしろの名前に a があるか、s がついているかを見よう。
There （ア is ／イ are） a big garden.（ア）
There （ア is ／イ are） three books.（イ）
（ア Do ／イ Is） there a garden?（イ）
Is there a cat? — Yes, （ア it is ／イ there is）.（イ）
There （ア was ／イ were） two cats.（イ）
There （ア isn't ／イ don't） a park near here.（ア）
ここが大事　1・2・5 はうしろの数。3・6 は be動詞の文に do を混ぜないこと。
4 は答え方です。Yes, it is. と言いたくなりますが、there を使います。
合言葉There is / are は 「ある・いる」。be動詞は うしろの名前の数で決まる。

レベル1チェック　文法あなうめ日本語に合うように、（　）に1語ずつ入れよう。

コツ　There のうしろを先に見て、1つか2つ以上かを決めよう。
  1. その近くに大きな庭があります。　There（is）a big garden near there.
    a garden は1つ。
  2. 本が3さつあります。　There（are）three books.
    several は「いくつかの」。
  3. その近くに大きな庭がありますか。　（Is）there a big garden near there?
    be動詞を前に出す。
  4. はい、あります。　Yes,（there）is.
    it ではなく there。
  5. いいえ、ありません。　No, there（isn't）.
    否定文の短い形。
  6. 部屋にねこが2ひきいます。　There（are）two cats in the room.
    two cats は2ひき。
  7. 机の上に本が1冊あります。　There is（a）book on the desk.
    1冊なので a。
  8. 以前そこに庭がありました。　There（was）a garden there before.
    過去で1つなので was。
  9. そこにねこが2ひきいました。　There（were）two cats there.
    過去で2ひきなので were。
  10. この近くに公園はありません。　There（isn't）a park near here.
    1つのものを否定文にする。

レベル2チェック　並べかえ（　）の語を正しい順にならべよう。文の最初は大文字、終わりにピリオドを。

コツ　There → be動詞 → 名前 → 場所、の順。
  1. その近くに大きな庭があります。　（ near there / There / a big garden / is ）
    There is a big garden near there.
    場所はいちばん後ろ。
  2. 本が3さつあります。　（ three books / are / There ）
    There are three books.
    are を選ぶ。
  3. その近くに大きな庭がありますか。　（ there / near there / Is / a big garden ）
    Is there a big garden near there?
    Is there が先頭。
  4. 部屋にねこが2ひきいます。　（ the room / in / two cats / There / are ）
    There are two cats in the room.
    「どこに」は後ろ。
  5. 机の上に本が1冊あります。　（ a book / is / on / There / the desk ）
    There is a book on the desk.
    a book は1冊。
  6. 以前そこに庭がありました。　（ before / There / a garden / was / there ）
    There was a garden there before.
    過去形の was。
  7. この近くに公園はありません。　（ isn't / here / a park near / There ）
    There isn't a park near here.
    否定文の形。

レベル4チェック　自由英作文自分の部屋や教室に何があるかを書こう

条件
  • There is ～. の文を 1つ以上
  • There are ～. の文を 1つ以上
