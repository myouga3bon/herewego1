I want to ～.

1きほんの文

「～したい」と言いたいときは、want to を使います。
　そのうしろにはかざりのない「もとの形」の動詞を置きます。

I want to go to America.わたしは アメリカに 行きたいです。
I want to see pandas.わたしは パンダを 見たいです。
I want to be a doctor.わたしは 医者に なりたいです。

3つとも want to のうしろが go・see・be ともとの形になっていますね。
　ここがポイントです。

きほんの文を3回音読して、さらに3回ずつ書き写そう

want だけでは「ほしい」という意味です。

3いちばん大事｜to をつけるか つけないか

ここが今回のヤマです。
　1-3 の can と、今回の want to で、まったく逆になります。

◯ to が必要「～したい」

want のあとに to。
✕ to はいらない「～できる」

合言葉：want には to、can には to なし

want to ＋ もとの形　can ＋ もとの形　 どちらも「もとの形」というところは同じです。
✕ I can to swim ✕　✕ I want swim ✕

おぼえ方は「to がつくのは want だけ」。
　うしろが もとの形になるのは、どちらも同じです。

4ing との区別

3-2 で習った ing とも混ざりやすいところです。
　前にあることばで決まります。

前にあることばうしろの形れい文
like（好き）～ingI like swimming.
can（できる）もとの形I can swim.
want to（したい）もとの形I want to swim.

ing になるのは like のうしろだけと考えておけば、しばらくは困りません。

5want to be で「～になりたい」

「医者になりたい」のように、しょうらいの夢を言うときは want to be を使います。

I want to be a doctor.　わたしは 医者に なりたいです。
be は am・are・is のもとの形です。I want to am ～. とは言いません。

職業には a をつけます（a doctor・a teacher・a singer）。
　「1人」だからです。

名前　　　　　　　　　　　

A　説明の（　）をうめよう語群から選びます（同じ語を2回使ってもよい）

  1. 「～したい」は I want（to）＋ 動詞.　want と to は（（2語））セット。
  2. to のうしろの動詞は（（もとの形））にする。
  3. （（can））のうしろには to をつけない。
  4. 「～になりたい」は want to（be）。これは am・are・is のもとの形。
  5. like のうしろは（（ing））の形になる。want to のうしろとはちがう。
語群：to ／ be ／ can ／ ing ／ もとの形 ／ 2語
なぜ？　to は「これから～へ向かう」というイメージのことば。これからしたいことを表すので want と相性がよいのです。
can は「できる力を持っている」という意味で、これから向かうわけではないので to がいりません。

B　to はいる？ いらない？（　）に to か × を書こう

ここがいちばん大事。（　）の前を見ましょう。want なら to、can なら ×。
1. I want（to）swim.
2. I can（×）swim.
3. I want（to）go to Paris.
4. I can（×）cook.
5. I want（to）be a doctor.
6. I can't（×）dance.
7. I want（to）see pandas.
8. I can（×）run fast.
9. I want（to）eat sushi.
10. I can（×）sing well.
見つけ方　（　）のすぐ前を見るだけ。
want → to（1・3・5・7・9）　can・can't → ×（2・4・6・8・10）
どちらの場合も、そのうしろの動詞はもとの形です。

C　正しい文には ○、まちがっている文には ✕ を書こう

1. I want to swim.○
2. I want swim.✕
3. I can swim.○
4. I can to swim.✕
5. I want to be a doctor.○
6. I want to am a doctor.✕
7. I want to see pandas.○
8. I want to going to Paris.✕
直し方　2 → I want to swim.（to を足す）　4 → I can swim.（to を消す）
6 → I want to be a doctor.（am → be）　8 → I want to go to Paris.（ing を取る）

D　うしろの形　正しいほうを選ぼう

like → ing／can → もとの形／want to → もとの形。
1. I want to（ア swim ／イ swimming）.（ア）
2. I like（ア swim ／イ swimming）.（イ）
3. I can（ア swimming ／イ swim）.（イ）
4. I want to（ア be ／イ am）a doctor.（ア）
5. I like（ア dancing ／イ dance）.（ア）
6. I want to（ア going ／イ go）to Paris.（イ）
ここが大事　ing になるのは like のうしろだけ（2・5）。
can（3）も want to（1・4・6）も、うしろはもとの形です。4の be は am のもとの形。
合言葉want to のうしろはもとの形。to を忘れない。can には to をつけない。
ぜんぶ終わったら押そう

レベル1チェック　文法あなうめ日本語に合うように、（　）に1語ずつ入れよう。

コツ　「～したい」なら want to、「～できる」なら can、「～が好き」なら like ～ing。
  1. わたしは泳ぎたいです。　I want（to）swim.
    want to で2語セット。
  2. わたしはアメリカに行きたいです。　I want to（go）to America.
    to のうしろは もとの形の go。
  3. わたしは医者になりたいです。　I want to（be）a doctor.
    「～になる」は be。am ではありません。
  4. わたしは泳ぐことができます。　I（can）swim.
    「できます」は can。to はいりません。
  5. わたしは泳ぐことが好きです。　I like（swimming）.
    「好きです」なので ing の形。1・4番とくらべよう。
  6. わたしはパンダを見たいです。　I（want）（to）see pandas.
    （　）が2つ。want → to。
  7. わたしは先生になりたいです。　I want to be（a）teacher.
    職業には a をつける。
  8. わたしはすしを食べたいです。　I want to（eat）sushi.
    もとの形の eat。eating にしない。
  9. わたしは料理をすることができません。　I（can't）cook.
    「できません」は can't。to はつけない。
  10. わたしはパリに行きたいです。　I（want）（to）go to Paris.
    6番と同じ形。want to ＋ もとの形。

レベル2チェック　並べかえ（　）の語を正しい順にならべよう。文の最初は大文字、終わりにピリオドを。

コツ　語群に to があれば want のすぐうしろに置きます。
  1. わたしは泳ぎたいです。　（ swim / to / I / want ）
    I want to swim.
    I → want → to → 動詞 の順。
  2. わたしはアメリカに行きたいです。　（ to America / want / I / go / to ）
    I want to go to America.
    to が2回出てきます。1つめは want のうしろ。
  3. わたしは医者になりたいです。　（ a doctor / be / I / want / to ）
    I want to be a doctor.
    a doctor でひとかたまり。
  4. わたしは泳ぐことができます。　（ swim / I / can ）
    I can swim.
    語群に to がない。ないものは使えません。
  5. わたしはパンダを見たいです。　（ pandas / to / see / I / want ）
    I want to see pandas.
    1番と同じ形。
  6. わたしはおどることが好きです。　（ dancing / like / I ）
    I like dancing.
    語群が dancing。like とセットです。
  7. わたしはすしを食べたいです。　（ sushi / want / eat / I / to ）
    I want to eat sushi.
    want → to → eat → sushi。
ぜんぶ終わったら押そう

レベル3チェック　和文英訳次の日本語を英語にしよう。

  1. わたしは泳ぎたいです。
    I want to swim.
    to を落とさないこと。
  2. わたしはアメリカに行きたいです。
    I want to go to America.
    to が2回。国名は大文字ではじめる。
  3. わたしは医者になりたいです。
    I want to be a doctor.
    be と a の2つを忘れない。
  4. わたしは泳ぐことができます。
    I can swim.
    to はいりません。1番とまちがえないこと。
  5. わたしはすしを食べたいです。
    I want to eat sushi.
    eat はもとの形。
  6. わたしはおどることが好きです。
    I like dancing.
    「好きです」なので ing。3つの形がそろいました。
want to ／ go to America ／ be a doctor ／ can ／ eat sushi ／ dancing

レベル4チェック　自由英作文じぶんの「したいこと・なりたいもの」を書こう

条件
  • I want to ～. の文を 2つ以上
  • I want to be ～. の文を 1つ
  • I can ～. の文も 1つ 入れる（to をつけない）
書き方の例I want to go to America. I want to see pandas.
I want to be a teacher.
I can swim.
これは例です。同じでなくてかまいません。行きたい場所・見たいもの・食べたいもの・なりたい職業 から選ぼう。
want のうしろに to がある to のうしろは もとの形 can に to をつけていない 職業には a をつけた
書けたら 見直しじぶんの文の to に○をつけよう。can のうしろに to がついていたら、そこがまちがい。
